2. 取得する情報

当社は、本サービス等の提供にあたり、以下の情報を取得することがあります。

(1) アンケート回答者（一般のお客様）に関する情報

  • 性別、来店回数などの属性情報（アンケート回答による任意入力）
  • 来店に関するご感想・ご意見（自由記述を含むアンケート回答内容）
  • LINEユーザーID、LINE表示名等（LINEログイン・LIFF機能をご利用いただいた場合）
  • 抽選キャンペーンへの参加状況および結果
  • 口コミ投稿のために生成された文案、および実際に投稿された口コミの内容（Googleの口コミ投稿画面を通じてお客様ご自身が投稿される場合を含みます）

(2) 店舗オーナー・スタッフ等（本サービス管理画面の利用者）に関する情報

  • メールアドレス、パスワード（不可逆的に暗号化ハッシュ処理を施して安全に保存します）
  • 氏名、所属店舗情報
  • ログイン履歴、操作履歴

(3) Googleサービスを通じて取得する情報

  • Googleビジネスプロフィールに関する情報（店舗のクチコミ内容、星評価、投稿文、パフォーマンス指標等）。これらは、店舗のオーナー様の同意・連携認可に基づき、当社の管理するGoogle Workspaceアカウントを通じてGoogle Business Profile APIにより取得・利用します。
  • Google Driveに保存する画像データ（本システムが作成したファイルおよびユーザーが指定した写真アセットにのみアクセスする権限（drive.fileスコープ）を用います。ユーザーの既存のGoogle Drive内の他のファイルには一切アクセスしません）

(4) 技術的情報

  • Cookie、セッション情報、IPアドレス、ブラウザ情報、本サービス等の利用状況に関する技術的メタデータ

3. 利用目的

当社は、取得した情報を以下の目的のためにのみ利用します。

  1. 本サービス等の提供・運営（アンケートの実施、抽選キャンペーンの実施、LINE公式アカウントを介した通知・クーポンの送信を含みます）
  2. AI（Anthropic社のClaude API）を用いた口コミ文案・返信文案・経営アドバイスの自動生成
  3. Googleビジネスプロフィールに関する口コミの管理・返信投稿・パフォーマンス分析、および自動投稿機能（最新情報）の提供
  4. 店舗オーナー・スタッフ向けの店舗運営改善および顧客動向の分析レポートの作成・提供
  5. 本サービス等の維持・改善、バグ修正、セキュリティ対策、不正利用の防止、およびお問い合わせへの対応

4. 第三者への提供・業務委託

当社は、本サービス等の提供およびインフラ運用のために、以下の外部クラウドサービス（データ処理の委託先を含みます）を利用しています。各委託先とは機密保持やデータ保護に関する契約を締結、またはそれぞれの事業者が定めるプライバシーポリシーに同意し、万全のセキュリティ下で管理しています。

  • Google LLC： Google Business Profile API、Google Drive API、およびGoogle OAuthによる認証処理
  • Anthropic PBC： Claude APIによるAI文章・アドバイス生成（送信されたデータはAIの学習には使用されません）
  • LINEヤフー株式会社： LINE Messaging API、LINEログインによる認証・通知配信
  • Supabase, Inc.： データベース（PostgreSQL）のセキュアなホスティング
  • Vercel Inc.： Webアプリケーションのサーバーレスホスティング
  • Upstash, Inc.： バックグラウンド自動投稿処理等の非同期処理のためのメッセージキュー管理

上記委託先、および法令に基づく開示請求がある場合を除き、事前にユーザーの同意を得ることなく第三者へ個人情報を提供・開示することは一切ありません。

5. Googleユーザーデータの限定使用ポリシー（Limited Use Policy）の遵守

本サービス等がGoogle APIから取得する情報の利用および他アプリへの移行は、制限付き使用要件を含む Google API Services User Data Policy（Google API サービス：ユーザーデータポリシー）に厳格に準拠します。

  • Google APIから取得したロケーションデータや写真アセットは、本サービス等の機能（自動投稿、口コミ管理、ダッシュボード表示）を提供する目的以外には利用しません。
  • 取得したGoogleユーザーデータを、広告配信、マーケティング、第三者への販売、ユーザープロファイリング等の目的で転用することは絶対にありません。

6. 安全管理措置

当社は、取得した情報の漏えい、滅失又は毀損の防止その他の安全管理のため、以下を含む高度な措置を講じています。

  • LINE公式アカウントのアクセストークン等の極めて機密性の高い資格情報は、AES-256-GCM方式を用いてデータベースに強固に暗号化して保存
  • インターネット上の通信はすべてSSL/TLS（HTTPS）により暗号化
  • アクセス制限（最小特権原則）の設定、およびサーバーセキュリティ監視の徹底

7. 保存期間

取得した情報は、利用目的の達成に必要な期間、または法令に定める期間保存し、その後は復元不可能な方法で速やかに削除します。契約店舗の解約・退会時のデータ取扱いについては、サービス利用契約の定めに基づき、責任を持ってデータベースから完全消去します。

8. お客様の権利

一般のお客様（アンケート回答者）、および店舗オーナー・スタッフは、ご自身の登録個人情報の開示、訂正、利用停止、削除等をいつでも請求することができます。ご希望の場合は、下記お問い合わせ窓口までご連絡ください。ご本人であることを確認のうえ、法令に従い合理的な範囲で速やかに対応いたします。

9. Cookie（クッキー）等の利用

本サービスでは、ログイン状態の安全な維持、セッション管理、および利便性向上のためにCookieを利用することがあります。ブラウザの設定によりCookieの利用を拒否・制限することが可能ですが、その場合、本サービスの一部機能（管理画面へのログイン状態維持など）が正常にご利用いただけなくなることがあります。

10. 本ポリシーの変更

当社は、サービス内容の拡充や関係法令の改定等に伴い、必要に応じて本ポリシーを合理的な範囲で随時変更することがあります。変更後のポリシーは、本サービス等の画面上または公式サイト上に掲載された時点から効力を生じるものとします。
